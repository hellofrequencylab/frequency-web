Spacing scale & rhythm

One ramp serves everything. In-app work uses three named rhythms so screens feel consistent without anyone measuring: section between page blocks, group between rows and cards, tight within a row. Marketing sections all breathe on one heartbeat.

The three in-app rhythms

section · --space-8

Between page sections and rail modules. 2rem.

group · --space-3

Between rows in a list, cards in a grid. 0.75rem.

tight · --space-1

Within a row: glyph to label, value to unit. 0.25rem.

The marketing heartbeat

--space-sectionclamp 5–6remDefault content section. Every public page uses this.
--space-section-tightclamp 3.5–4remStatements and banners.
--space-section-looseclamp 6–8remHero beats and the dark band.
--space-ctaclamp 6–7remThe beta close.

Space before borders. If two things need separating, add space. A rule is the second resort, a box the third.

One heartbeat per site. Every marketing section uses a --space-section* token, so scrolling feels even.

Gap, not margin. Sibling groups lay out with flex/grid and gap, so spacing survives reordering.

Never a value off-ramp. No 13px, no 1.1rem. The ramp has enough steps.
