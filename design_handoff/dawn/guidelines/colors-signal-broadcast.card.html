Signal & Broadcast

Both exist so a specific meaning has a colour, not so pages have variety. Signal is pool water in shade — a deep green-leaning teal for the rare secondary moment. Broadcast is a bright robin’s-egg blue that means a message is involved: Dispatches, onboarding, comms. Using it for a generic button is the mistake.

Distinct hues on purpose. Signal leans green, Broadcast leans cyan, Move leans blue. Side by side they must never be mistaken for each other.

Broadcast means a message. A Dispatch, an onboarding nudge, a comms setting. Not a general-purpose button.

Neither one competes with amber. If both appear on a screen, amber owns the primary action.

Never green. True green does not exist in this system — success is a teal for exactly this reason.
