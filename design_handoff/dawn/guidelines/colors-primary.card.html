Foundations · Color

Primary · amber-gold

One accent carries the whole system. Amber is a CTA, an active state, a glow, and a number worth noticing — nothing else. A second accent competing for the same job is the fastest way to make a page look generic.

The four steps

--color-primary
#E2912F
Fills. Buttons, the active rail row’s tint source, every glow.
--color-primary-hover
#CE8023
Hover and press only. Never a resting fill.
--color-primary-strong
#9A5E12
Amber as TEXT on light. The only step that passes on cream.
--color-primary-bg
#FBEFD9
The tint behind an active row, a chip, a callout.

In use

Create primary
Active row primary-bg + strong
primary + .halo

One accent. If something needs to stand out next to amber, make it quieter — do not introduce a second colour.

Never amber text on cream. Use primary-strong. The base step fails contrast below 24px.

Dark mode inverts the pair. primary lightens to #F2B14E and primary-strong becomes the same value, because deep amber disappears on ink.

Amber marks, it does not decorate. Every amber pixel should be answering "where do I click" or "what changed".
