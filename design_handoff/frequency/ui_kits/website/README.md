# Website UI kit

The public marketing homepage, **"One network, two sides."** All copy is the owner's, used verbatim. Headlines are pulled from that copy.

- The built site lives at the project root, one page per file (Home.html, People.html, Spaces.html, …) sharing `site.css`.
- Energy mapping follows `guidelines/brand-strategy.md`: Night A for the hook and the closer, Thermal for the places side, and the day coast for the people side.
- Interactions: the nav theme follows scroll, the Circle meter fills on view, live standing lines animate on the Space rankings, and the loop ring steps through its stages. All of it respects reduced motion.
- Demo names (Cedar Studio, Juniper, Low Tide Café, Bird Rock) are placeholders.
