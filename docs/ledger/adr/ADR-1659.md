## ADR-1659: The teaser gate is deleted, and the Circle feed renders as it did with the flag off (LIVE-680)

**Status:** Accepted · 2026-09-29 · backlog `LIVE-680` (closed here) · owner ruling "Retire it" (ADR-1624) · no migration

**Context.** `lib/teaser.ts` carried `TEASER_GATE_ENABLED = false`, a role floor and a 30-second preview length. `components/teaser-gate.tsx` was a client wrapper that would have let a below-tier viewer peek at gated content, then blurred it behind an upgrade prompt with a localStorage meter (`freq_teaser_meter_v1`). It had one mount, the Circle feed, and with the flag off `teaserAllowed()` returned true for everyone, so the wrapper only rendered its children. The paywall rework (ADR-1294) moved premium gating to `CrewGate`, `UpsellTease` and the meter upsell, and docs/VALUE-LADDER.md already listed the teaser gate as a third gating idiom. The owner ruled on 2026-09-29: retire it.

**Decision.**

1. **Delete, do not park.** `lib/teaser.ts`, `components/teaser-gate.tsx` and its test are removed. The flag is a code constant, not a database row, so nothing in the database changes.
2. **The one mount unwraps to what it already rendered.** `components/widgets/circles/circle-feed.tsx` returns its `<section>` directly. With the flag off the wrapper emitted exactly those children, so no viewer sees a change.
3. **Pointers to the deleted file are reworded, not left dangling.** Three code comments that said "mirrors components/teaser-gate.tsx" now describe the pattern. docs/TEASER-GATE.md section 2 and the VALUE-LADDER dead-code table say the gate is retired and point at the idioms that replaced it.

**Rejected.** Keeping the gate for the paid launch (the ruling closes that; a future paywall starts from `CrewGate` / `UpsellTease`). Deleting docs/TEASER-GATE.md outright (its section 1 still documents the header quick-nav).

**Consequences.** One less client component and one less localStorage key in the Circle route's bundle. The Circle feed is unchanged for every viewer. Help does not change: the gate never switched on, so no member ever saw it.

**Rows.** `LIVE-680` closed here. Test: `components/widgets/circles/circle-feed.test.tsx` renders the feed for a signed-in non-member and a member and asserts a plain section with no preview timer, upgrade prompt, blur or dialog.
