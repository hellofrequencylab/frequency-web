## ADR-1634: The open CodeQL set is fixed in code as one set: 27 alerts across 11 rules close here, the 10 upload-preview alerts close with HYG-142, and nothing is dismissed

**Status:** Accepted · 2026-09-29 · backlog `HYG-143` (closed here) · applies the rule of [ADR-1637](DECISIONS.md) §3 ("fix, never dismiss") to the whole alert list · re-tested first per [ADR-1082](DECISIONS.md) · numbered 1634 by the orchestrator's assignment

**Context.** The owner's screenshot of GitHub code scanning read 36 open CodeQL alerts, and no session tool reads that list. So the set was reproduced locally the way `.github/workflows/codeql.yml` builds it: CodeQL 2.27.1 (the current bundle), a `javascript-typescript` database over a `git archive` of `origin/main` at 3be7bedd4 with `design_handoff` and `public/maplibre` removed (the workflow's `paths-ignore`), and the `security-and-quality` suite. It reported 37 results in 12 rules. The one-result gap to the screenshot is not resolvable without the API (a result GitHub files as test code, or a scan that ran after the screenshot, would each explain it); every one of the 37 is handled below, so the gap cannot hide an unfixed alert.

The "After" column is the same suite over this branch with `lib/safe-image-src.ts` taken from the HYG-142 branch before it merged: 0 results. The copy that merged (#3047) keeps the shape CodeQL reads, since every return is `null` or a value an anchored regexp just accepted, and `safeUploadPreviewSrc` returns only what `safeImageSrc` returned; it was not re-scanned here, so the next `main` scan is the measurement. Five of the ten `js/xss-through-dom` sites were never named by a row (both previews in `connections/new/creator.tsx`, `events/scan/creator.tsx`, `event-spark.tsx`, the induction avatar); all render through `safeUploadPreviewSrc`, so they close with that helper and need no change here.

**Decision.** Each alert is closed by the smallest change that makes the finding untrue, not by reshaping code until the query stops matching.

1. **A request value used as an object key passes an anchored allowlist first** (`js/remote-property-injection`). The business seeder's `updateImportField` refuses any path that is not a top-level field, `contact.<field>` or `offerings[<n>].<field>` (`FIELD_PATH`) before it reads or writes; the existing `__proto__`/`constructor`/`prototype` denylist stays at each write, because `constructor` is a valid identifier. The guest seat's `cleanAnswers` keeps only uuid keys, which is all `update_guest_seat` ever accepts. `withPageDoc` writes only a slug of the nav's own shape (`SLUG_RE`) and is otherwise a no-op. The same allowlist shape [ADR-1637](DECISIONS.md) set for image URLs: the barrier is an anchored, wildcard-free regexp test, because that is what a reader and the analysis can both check.
2. **A security check runs unconditionally** (`js/user-controlled-bypass`). The click redirect verifies the destination's signature first, on every request, and only then reads the send, so no query parameter decides whether the check runs and a forged link costs no database read (`verifyClickUrl` now takes a null destination and answers false). The demo decay action no longer takes a dry-run flag from the browser: it is two actions, `previewDemoDecay` and `runDemoDecay`, each janitor-gated. (The second alert was a name heuristic on `deletePlansByAuthors`; removing the client-sent flag is the real improvement it pointed at.)
3. **Identifiers come from a CSPRNG** (`js/insecure-randomness`). The observe visit id falls back from `randomUUID` to `getRandomValues` (an http preview has no secure context) and never to `Math.random`; the demo generator draws on `node:crypto` `randomInt`.
4. **Each code-quality alert removes the dead or wrong line it names.** A never-null parameter loses its null check, an unused `statuses` parameter and its filter go, two initial values both branches overwrite go, a `myProfileId &&` already proven true goes, the Spark bonus is built from empty instead of merging into a container that is always empty there, `connectBindingState` asks `awaitingConnect` (beside `CONNECT_WIRED` in `personas-core.ts`) instead of branching on an imported constant, a test line that repeated the assertion above it goes, and the enrollment-error mock the test declared but never set now drives a new test.
5. **Script gates keep their behaviour.** `check-build-fanout` reads a chunk once and measures what it read (the stat-then-read race); `help-autodoc` lets only a digits-only PR number from the event file into the API path; `htmlToText` ends script, style and noscript elements at `</tag` plus anything up to `>`, as browsers do; the seat migration test escapes every RegExp metacharacter.

**Rejected.** Dismissing any alert as a false positive, including the two that are arguably so (the decay flag is janitor-gated; the event file is GitHub's own): [ADR-1637](DECISIONS.md) §3 rules it out, and in both cases a small code change was better code anyway. Excluding queries in the workflow config (it would also hide the next real finding in that class). Inline suppression comments (GitHub code scanning does not honour them). A shared "safe key" helper across the three property-injection sites (their valid keys differ: a field path, a uuid, a page slug; one helper would be the loosest of the three).

**Consequences.** The next `main` scan after this row lands (HYG-142 is already on `main`) should read 0 open alerts; a dated read of the Security tab is still the owner's to take, since no agent reads it. Behaviour changes a person could notice: a seeder path outside the three shapes (including `contact.` with no field) is refused with the existing "could not be updated" message; a guest seat answer keyed by anything but a uuid is dropped before the RPC (the SQL dropped it anyway); the decay panel calls two actions. New tests: `app/(main)/e/c/[token]/route.test.ts`, `lib/analytics/observe.test.ts`, and cases in the seat actions, profile pages, business seeder, `htmlToText` and completion analytics suites. The row's `cmd` probe checks each fixed site's structure (and runs `htmlToText` on the junk end tags), and fails on `main`.

**Rows.** `HYG-143` (closed here).
