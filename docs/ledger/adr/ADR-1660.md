## ADR-1660: The perf baseline times the People directory at /network, where it renders (HYG-141)

**Status:** Accepted · 2026-09-29 · backlog `HYG-141` (closed here) · amends the H0-6 harness (`scripts/perf-baseline.mjs`, docs/OBSERVABILITY-BASELINES.md §2) · no migration

**Context.** ADR-172 moved the People directory into the Network hub. `app/(main)/people/page.tsx` is now a bare `redirect()` to `/network`. The perf harness still listed `people-directory` at `/people`, so a sample timed a 307 and never reached the directory query. The entry also named `lib/feed/feed-people.ts`, which the directory page does not import. The `--plans` text said to capture the plan as role `authenticated`, but the listing, `members_near` and the suggestions all read through the admin client.

Re-tested on 60567b67e before the change: the route was `/people`, and the page at that route only redirects. §2b holds no reading for this path (its dataset gate), so there was no stored baseline to re-take.

**Decision.**

1. **The entry samples `/network`** and names `app/(main)/network/page.tsx` (`directoryPromise`) and `lib/people-suggestions.ts`.
2. **`--plans` prints the listing query** (the capped `profiles` select with the `nexus_regions` join) and says to capture it as `service_role`, the role it runs as.
3. **The harness is importable.** `HOT_PATHS` is exported and `main()` runs only when the file is invoked directly, so a test import never samples, even with `PERF_BASELINE_BASE_URL` set.
4. **A test holds the consequence.** `scripts/perf-baseline.test.ts` resolves every concrete route the harness samples to its app page and fails when that page only redirects. The backlog probe runs the same check.

**Rejected.** Setting `redirect: 'manual'` in the sampler and reporting 3xx. That makes the harness notice at sample time, which is against a deployment. The check belongs in the tree, where no load is sent (LIVE-551).

**Consequences.** When §2b's gate opens, the People directory reading measures the directory. No request was sent to production or any deployment. Member-facing behaviour is unchanged.

**Rows.** `HYG-141` closed here. Tests: `scripts/perf-baseline.test.ts`.
