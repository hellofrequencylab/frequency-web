## ADR-1696: The scanner spec measures the app's response, not Vercel's cookie hop, and waits for the scanner's own re-load (LIVE-735)

**Status:** Accepted · 2026-09-30 · backlog `LIVE-735` (filed and closed here) · cause (d) of `LIVE-213`, named in #3109 · amends the LIVE-713 spec (ADR-1641) · test only, no product change

**Context.** pr-compare failed on every PR on `test/e2e/scan-camera.spec.ts`. The header test read `/scan` at `maxRedirects: 0` and found zero `Permissions-Policy` lines (run 36678631457). `playwright.config.ts` sends `x-vercel-set-bypass-cookie: true` on a protected preview, so the first request can be Vercel's cookie-setting redirect to the same URL, which carries none of the app's headers: the likeliest reading of zero lines on the first path read. `/scan` is the first path read, so the test measured the hop. The soft-navigation test gave the scanning line the 5 s default from `router.push`, across an RSC fetch, a mount and a full re-load of `/scan` on a cold preview, and lost that race intermittently (e2e-manual smoke job 109734068949).

**Decision.** The header test reads each path through `appResponse`: a redirect whose Location is the same origin, path and query is stepped over (at most three, then it throws); any other response, a signed-out `/scan` sent to `/sign-in` included, is the one measured, unfollowed, as before. The soft-navigation test waits for the `/scan` document request (a main-frame navigation, not a 3xx) that only the scanner's re-load makes, asserts it answered 2xx, and then gives the scanning line and the video 20 s. Every assertion stays: one header line, `camera=(self)` on `/scan`, `camera=()` on `/` and `/sign-in`, a running viewfinder, no denied card, a document loaded at `/scan`.

**Rejected.** Skipping or quarantining the spec on previews (it is the only browser proof of LIVE-713). Following every redirect (a `/scan` that redirected to a page with the wrong policy would then pass). A separate request context without `x-vercel-set-bypass-cookie` (it would measure a request shape no browser in the suite sends, and the browser tests in the same file still need the cookie).

**Consequences.** A protected preview and production read the same thing. A regression that stops the scanner re-loading fails at a named wait instead of a missing line of text.
