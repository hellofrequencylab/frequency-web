## ADR-1751: An unlisted event's public share page tells crawlers not to index it (SCAN-1014)

**Status:** Accepted · 2026-10-19 · backlog `SCAN-1014` · extends ADR-202 (unlisted is a link, not a listing) and ADR-903 (`public_event_by_slug` admits unlisted by slug) · corroborated by `lib/events/public-indexability.ts` and `app/(public)/events/[slug]/page.tsx`

**Context.** `public_event_by_slug` resolves an unlisted event because the slug is the link. It does not return `visibility`. The public ISR page at `/events/<slug>` always set a canonical and only noindexed past dates and extra series occurrences. SCAN-867 and SCAN-876 then made that page a full Event with a guest join box, so a crawler that saw the shared link could index an unlisted event. The member twin (`event-member-page.tsx`) already noindexes anything that is not strictly public. Premise re-tested 2026-10-19 on this tree: `generateMetadata` had no `unlisted` branch; anon RLS still admits unlisted rows; anon still has SELECT on `events.visibility` (kept by `20270330000000`). The row's claim that the anon enrichment read cannot see an unlisted row is stale: that read never filtered visibility, it just did not project the column, and `generateMetadata` never called it.

**Decision.** Read `visibility` server-side with the service role (the same cookie-free client the venue and join door already use, so the ISR window stays). Do not add an OUT column to `public_event_by_slug`: that is a DROP + CREATE of an anon-granted DEFINER, which enrichment already refused for `cover_url` and `time_zone`. An unlisted share page sets `robots: { index: false, follow: true }`, omits the canonical, and omits Event JSON-LD. The share card still renders: unlisted exists to be pasted. Public events are unchanged. Unlisted beats past and series robots, so an upcoming unlisted date cannot become indexable.

**Rejected.** Returning `visibility` from `public_event_by_slug`. Asking `generateMetadata` to call the full enrichment read (ticket tiers and payout readiness) just to pick up one column.

**Consequences.** `lib/events/public-indexability.ts`. No migration. Apply nothing.
