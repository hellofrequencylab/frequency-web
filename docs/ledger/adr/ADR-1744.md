## ADR-1744: The public event page shows the venue when the host has not hidden the address

**Status:** Accepted · 2026-10-14 · owner-ruled ("Show venue & city") · amends [ADR-1743](DECISIONS.md) (its "Not changed" paragraph), [ADR-186](DECISIONS.md), [ADR-825](DECISIONS.md), [ADR-1189](DECISIONS.md)

**Context.** ADR-1743 put the venue into the Event JSON-LD on `/events/<slug>` whenever the host left the address visible, and left the visible anonymous page on the city line, noting that the structured data now carried more than the page displayed and leaving that to the owner. The owner ruled (2026-10-14) that the page shows it too.

**Decision.** (1) The public event page (`app/(public)/events/[slug]/page.tsx`, which serves signed-out readers in both site designs) renders the where-line as `Venue · street, city` with a "Get directions" Maps link when `hide_address` is explicitly `false`. A `true`, `null` or unread flag keeps the city line and the "exact venue is shared with members who RSVP" note. (2) The line is composed by `publicPageWhere` (lib/events/visible-location.ts), which checks the flag a second time and omits blank parts, from the SAME server-side read the JSON-LD uses (`getPublicEventVenue`, lib/events/public-venue.ts). No second read, and the visible page and the structured data cannot disagree. (3) The anon column revoke (SCAN-209) stays: a hidden venue never reaches the browser, because the service-role read drops it on the server before render. (4) The signed-in page (`event-member-page.tsx`, both the DAWN and Frequency returns) already showed the venue for a visible address and keeps ADR-825's rule unchanged: exact address for registered viewers and managers when hidden. (5) Event lists stay city-level.

**Consequences.** `app/(public)/events/[slug]/public-venue-line.render.test.tsx` renders the real page: visible shows venue, street, city and the Maps link; hidden or unset shows the city and no street anywhere in the HTML. `lib/events/visible-location.test.ts` pins the blank-part rules. ADR-186's "city-level public surfaces" and ADR-825's hidden-address gate now read as the hidden-address case for the event detail page.
