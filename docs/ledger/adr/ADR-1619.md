## ADR-1619: PACKED_PER_RAW is 0.55, rounded up from the 2026-09-29 pair that uploaded 1.42 GB where the gate estimated 1.38 (HYG-136)

**Status:** Accepted · 2026-09-29 · backlog `HYG-136` (closed here) · amends the calibration in [ADR-1086](DECISIONS.md) / [ADR-1113](DECISIONS.md) (`HYG-015`) · numbered **1619** by the orchestrator's assignment on the `HYG-140` follow-up · no migration

**Context.** `scripts/check-cache-budget.mjs` can only see raw bytes. Vercel weighs the packed archive. The conversion is one whole-archive constant, `PACKED_PER_RAW`, last settled at 0.53 on 2026-08-19 from 1.32 GB packed over 2.513 GB raw, rounded up from 0.5254 so the gate fires early. A production build on 2026-09-29 printed both halves again: the gate estimated 1.38 GB at 0.53, and Vercel uploaded 1.42 GB against its 1.50 GB ceiling. Implied raw is 1.38 / 0.53 = 2.6038 GB; implied ratio is 1.42 / 2.6038 = 0.5454. The trim point is 1.40 GB estimated. The real archive was already past it, and a cache over 1.50 GB is discarded whole, `node_modules` included. That is the direction this file has always called dangerous.

**Decision.**

1. **`PACKED_PER_RAW` is 0.55.** Rounded up from 0.5454, the same rule as 0.5254 to 0.53: over-estimating costs a cold compile; under-estimating loses the install cache. The date on the constant is 2026-09-29.
2. **It stays one whole-archive ratio.** Vercel prints one packed number. A per-part split (node_modules vs Turbopack) cannot be measured from that pair. The mix has moved a little, compiler-heavier, not into the empty-cache 0.26 regime. Lowering toward 0.264 remains forbidden ([ADR-1113](DECISIONS.md)).
3. **Do not raise the ceiling or shrink the reserve.** The 1.50 GB ceiling is Vercel's. The 0.10 GB reserve stays. The next similar build will trim, which is the honest fail-safe. Compiler-cache growth between warm builds is `HYG-140`, not a budget edit.
4. **`HYG-015`'s two-sided band moves with the pair** to 0.52–0.56, so the done probe still forbids the empty-cache lowering and still fails a constant that hides this under-read.

**Rejected.** Separate ratios in this change (no per-part packed reading exists). Lowering the constant. Raising `TRIM_AT_PACKED_GB` or cutting `RESERVE_GB` to keep the estimate green.

**Consequences.** The gate's estimate sits on the high side of the 2026-09-29 pair. `HYG-015` still holds the "do not apply a node_modules-only ratio to a compiler-heavy mix" invariant. The next production log's `Uploading build cache` line is the check; if the mix moves again, re-derive from that pair, round up, do not raise the budget.

**Rows.** `HYG-136` closed here. `HYG-015` probe band amended in the same PR so a done row does not regress. `HYG-140` stays open.
