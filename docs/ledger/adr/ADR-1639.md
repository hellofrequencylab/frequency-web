## ADR-1639: A product review is refused unless the member has a settled order for that listing or a Journey sibling (LIVE-697)

**Status:** Accepted · 2026-09-29 · backlog `LIVE-697` (closed here) · amends the payments-off half of [ADR-598](DECISIONS.md) · no migration

**Context.** ADR-598 shipped product reviews with `verified_purchase` derived from a settled order, and allowed any signed-in member who was not the seller to leave one while payments were off. That TODO stayed in `app/(main)/marketplace/review-actions.ts` after payouts went live (OWN-046). Re-tested on this tree: `hasPurchasedProduct` ran, then `upsertProductReview` always ran. The flag labelled the row. It did not gate it.

**Decision.**

1. **`submitProductReviewAction` refuses unless `hasPurchasedProduct` is true.** The refusal is `Buy this to leave a review.`, parallel to `Sign in to leave a review.` A settled `paid` or `fulfilled` order for this product or a Journey sibling still counts, same helper as the label.
2. **The label stays derived.** Existing unverified rows stay visible. Editing still goes through the same gate, so a review left before this change cannot be updated without a settled order.
3. **The action is the wall.** `upsertProductReview` stays a write the caller has already authorized (moderation and tests). RLS is bypassed by the admin client, so the check has to live in the action.
4. **Surfaces.** The member Journey page passes `canReview` only when the member bought it. ISR Market and discover pages still hydrate the form from viewer chrome (`signedIn={false}` `canReview={false}`); the action refuses a non-buyer there.

**Rejected.** Gating on `host_payouts_enabled` as a second flag (payments are already on; the order is the proof). Putting the gate inside `upsertProductReview` (operators and tests write through it). A connect-only exception (the row named a settled order; those listings never write one).

**Consequences.** A signed-in member who never bought the listing cannot create or edit a review. A Journey re-price still counts as a purchase of the live listing. Help and the changelog say so.

**Rows.** `LIVE-697` closed here. Tests: `app/(main)/marketplace/review-actions.test.ts`.
