## ADR-1657: The signed-in walk of member surfaces closes on the owner's sign-off (LIVE-413)

**Status:** Accepted · 2026-09-29 · backlog `LIVE-413` (closed here) · no code change · no migration

**Context.** The 2026-09-18 survey left one item open: a signed-in walk of the member surfaces (feed, Circles, Events, Marketplace, a Space, a Journey sales page, compose, billing). LIVE-413 held it with a manual probe that closed only on a dated walk with pass/fail per surface. The walk needs a working account on production, so no agent could run it.

**Decision.**

1. **The owner's sign-off closes the row.** On 2026-09-29 the owner said: "We can sign off on task 3. Things are looking stable." Task 3 is this walk. The owner reported no defects, so no child rows are filed. No per-surface pass/fail notes were taken; the ruling is that the surfaces are stable as they stand.
2. **The manual probe becomes a cmd probe that holds what was signed off.** For each of the eight surfaces the probe reads the entry file and the token that makes it that surface, and a test file that covers the same piece and still has cases:

   | Surface | Entry file names | Test file covers |
   |---|---|---|
   | feed | `app/(main)/feed/page.tsx`: `FeedList` | `components/feed/feed-list.test.tsx` |
   | Circles | `app/(main)/circles/page.tsx`: `getCirclesIndexData` | `app/(main)/circles/circle-access-rail.test.ts` |
   | Events | `app/(main)/events/page.tsx`: `getEventsIndexData` | `app/(main)/events/index-data.test.ts` |
   | Marketplace | `app/(main)/marketplace/page.tsx`: `commerceSurfaceHref` | `lib/marketplace/last-visited.test.ts` |
   | a Space | `app/(main)/spaces/[slug]/layout.tsx`: `AccentScope`, plus the public `(profile)/[page]/page.tsx` | `app/(main)/spaces/[slug]/accent-scope-coverage.test.ts` |
   | a Journey sales page | `app/(main)/journeys/[slug]/page.tsx`: `getJourneyOffer` | `lib/journeys/paid.test.ts` |
   | compose | `components/feed/composer.tsx`: `createPost` | `app/(main)/feed/actions.test.ts` |
   | billing | `app/(main)/settings/billing/page.tsx` | `app/(main)/settings/billing/bundle-offer.test.ts` |

   It passes on main today. Mutation-checked: removing `lib/journeys/paid.test.ts`, renaming `createPost` in the composer, or removing the public Space page each fails it and names the surface.

**Rejected.** Keeping the row open for a written per-surface log (the owner ruled it closed; a second walk is not asked for). A probe that runs the test suite (LIVE-034: probes do not spawn the runner; the suite already runs in CI).

**Consequences.** The survey's last open item is closed. The probe measures presence and coverage, not a fresh walk: a surface that is deleted, or loses the test that covers it, reopens the row in `check:backlog`. A regression inside a surface is caught by its own tests, not by this row.

**Rows.** `LIVE-413` closed here.
