# Format:  <slug>  <coded-component-count>

# One row per slug in EDITABLE_PAGES (lib/page-editor/data.ts). The count is how many top-level
# React components the route file still declares BESIDE its default export — the coded body that
# duplicates the Puck template an operator edits. The gate requires the measured count to MATCH:
# a rise is new duplicate truth and is refused; a fall means a body retired and the number here
# has to come down with it, in the same PR that earned it.
#
# WHY COMPONENTS AND NOT LINES. Lines are the figure docs/FINALIZE-PLAN.md quotes, and they are
# the wrong thing to gate on: a copy edit moves the number for reasons that have nothing to do
# with the duality. A top-level component is a structural fact. Lines are printed by the gate as
# context and never checked.

# sibling component rather than actually retiring, the number falls and this gate will ask you to
# book a win you did not earn. Say so in a comment on the line when that happens.
